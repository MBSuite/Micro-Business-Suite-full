# 📖 คู่มือการลงบันทึกใบแจ้งหนี้ซัพพลายเออร์ (Supplier Invoice Guide)
*ปรับปรุงล่าสุด: 9 เมษายน 2026*

> ⚠️ **พักการใช้เลขบัญชีในคู่มือนี้จนกว่าจะ reconcile:** code ปัจจุบัน map Input VAT เป็น `1140`, Accounts Payable เป็น `2111` และ category `ค่า License/Software` ไป `5340` (ค่าเสื่อมราคา) ซึ่งขัดกับเลข/ความหมายในคู่มือนี้ ต้องยืนยัน COA ที่ถูกต้องกับผู้ทำบัญชีและแก้ code/document ให้ตรงก่อนใช้บันทึกจริง
>
> WHT ก็ยังไม่ยืนยัน: หน้า voucher ส่ง `wht_amount` แต่ server action อ่าน `withholding_amount` จึงอาจไม่บันทึก WHT ที่ผู้ใช้เลือก

คู่มือนี้สรุปขั้นตอนการทำงานเมื่อได้รับใบแจ้งหนี้ (Invoice/Bill) จากซัพพลายเออร์ (เช่น Google, Microsoft หรือตัวแทนจำหน่าย License) ในฐานะที่เราเป็น **"ตัวกลาง"**

## 1. ขั้นตอนการบันทึก (Workflows)
1. เข้าไปที่เมนู **Expenses** (ค่าใช้จ่าย)
2. กดปุ่ม **+ Add Expense**
3. กรอกข้อมูลดังนี้:
   - **Payee (ผู้รับเงิน):** เลือกชื่อซัพพลายเออร์
   - **Date (วันที่):** เลือกวันที่ตามหน้าใบแจ้งหนี้
   - **Amount (ยอดรวม):** ใส่ยอดรวมทั้งหมด
   - **VAT:** ระบุ VAT ตามใบกำกับจริง; code mapping ปัจจุบันใช้ account reference `1140` แต่ต้องยืนยันกับผังบัญชีจริง
   - **Category (หมวดหมู่):** เลือกตามรายการจริง; การ map License ใน code ปัจจุบันยังชี้ไป `5340` จึงต้องแก้/ยืนยันก่อนบันทึก production

## 2. การบันทึกบัญชีอัตโนมัติ (Journaling)
เมื่อกดบันทึก ระบบจะลงสมุดรายวันซื้อ (Purchases Journal) ให้ดังนี้:
การลงบัญชีที่อธิบายไว้ด้านล่างยังไม่ควรถือเป็น mapping ที่รับรองแล้ว: source ปัจจุบันใช้ `INPUT_VAT=1140`, `ACCOUNTS_PAYABLE=2111` และ category License ไป `DEPRECIATION=5340`; ให้ผู้ทำบัญชียืนยัน chart of accounts และการจัดประเภทก่อนใช้

## 3. ขั้นตอนถัดไป: การจ่ายเงิน (Payment & WHT)
เมื่อถึงเวลาจ่ายเงินให้ซัพพลายเออร์:
1. ไปที่ใบ Expense นั้น แล้วกด **"Create Payment Voucher"**
2. ตรวจประเภทเงินได้/คู่สัญญาและอัตรากับผู้ทำบัญชีก่อนเลือก WHT; ไม่ใช่ทุก License ใช้อัตราเดียวกัน
   - แม้ UI จะแสดงอัตรา WHT แต่เส้นทาง voucher ปัจจุบันมีชื่อ field ไม่ตรงกัน; ตรวจ record และ journal ว่ามี WHT จริงก่อนปิดรายการ

## 4. รหัสบัญชีที่เกี่ยวข้อง (Quick Reference)
- **1140:** code constant ปัจจุบันสำหรับ Input VAT (ยืนยันกับ COA จริงก่อนใช้)
- **2111:** code constant ปัจจุบันสำหรับ Accounts Payable (ยืนยันกับ COA จริงก่อนใช้)
- **2130:** code constant ปัจจุบันสำหรับ WHT payable
- **5340:** code ปัจจุบัน map category License ไปยังบัญชีนี้; ความหมายเป็นค่าเสื่อมราคา จึงเป็น discrepancy ที่ต้องแก้ก่อนใช้จริง

---
*หมายเหตุ: ในกรณีที่เราเป็นตัวกลาง (Intermediary) ยอด Invoice จากซัพพลายเออร์คือ "ต้นทุน" ของเรา และยอด Invoice ที่เราเปิดให้ลูกค้าคือ "รายได้" ของเรา ส่วนต่างคือ "กำไรขั้นต้น" ครับ*
